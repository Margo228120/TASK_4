В ООО «Рога и Копыта» уже есть база данных (день 2) и API (день 3). Но менеджеры не хотят открывать Swagger и писать запросы руками: им нужна обычная программа с окнами, таблицами и кнопками.

## Шаг 4. Осмотрись

Все задания — в папке `ShopDesktop`:

| Файл | Что в нём |
|---|---|
| `MainWindow.axaml` | **Как окно выглядит**: таблицы, поля ввода, кнопки |
| `MainWindow.axaml.cs` | **Что окно делает**: что происходит при нажатии кнопок и выборе в списках. Почти все задания здесь |
| `Api.cs` | Общение с API. Готово, не трогай |
| `Models/Models.cs` | Классы `Product`, `Order`... — такие же, как в API |

**Как связаны два файла окна.** В `MainWindow.axaml` у элемента есть имя и событие:

```xml
<TextBox x:Name="SearchBox" TextChanged="Filter_Changed" />
```

- `x:Name="SearchBox"`: в коде к этому полю можно обратиться по имени. Например, `SearchBox.Text` — это текст, который ввёл пользователь.
- `TextChanged="Filter_Changed"`: когда текст меняется, вызывается метод `Filter_Changed` из `MainWindow.axaml.cs`.

**Как таблица показывает данные.** У таблицы (`DataGrid`) есть `ItemsSource` — список, который она показывает. Столбцы описаны в `.axaml`:

```xml
<DataGridTextColumn Header="Название" Binding="{Binding Name}" />
```

`Header` — заголовок столбца. `{Binding Name}` означает «в этом столбце показывай свойство `Name` каждого товара».

### Шпаргалка по C#

Почти всё это ты уже видел в дне 3.

```csharp
var text = SearchBox.Text;                 // var — переменная; тип C# поймёт сам
if (x == 5) { ... }                         // == сравнить, != не равно, && и, || или
products.Where(p => p.Price > 100)          // отобрать товары, у которых цена больше 100
items.Sum(i => i.Quantity)                  // сложить количество по всем строкам
list.Count                                  // сколько элементов в списке
$"Найдено: {count}"                         // строка, в которую подставляется значение count
var order = OrdersGrid.SelectedItem as Order;  // выбранная строка таблицы как заказ (или null, если ничего не выбрано)
var products = await Api.GetProducts();     // await — «дождись ответа от API»
return;                                     // выйти из метода, дальше код не выполняется
```

### Задание 3. Поиск

Напиши в поиске `Кофе`, и найдутся три товара. А теперь напиши `кофе` с маленькой буквы, и не найдётся ничего.

**Что должно быть:** поиск не обращает внимания на большие и маленькие буквы.

**Проверь себя:** `кофе`, `КОФЕ` и `Кофе` находят одно и то же: товары 5, 6, 17.

<details><summary>Подсказка</summary>

</details>

## Если что-то пошло не так

- **«Не получилось связаться с API»** — API не запущено, или ты закрыл его терминал. Шаг 2.
- **`dotnet run` пишет, что файл используется другим процессом** — программа уже открыта. Закрой её окно и запусти снова.
- **Не собирается, много красных ошибок** — читай **первую** ошибку: в ней есть имя файла и номер строки. Чаще всего это пропущенная `;`, скобка `}` или опечатка в имени.
- **Программа сама закрылась** — посмотри в терминал, там будет текст ошибки. Часто это значит, что выключилось API.
- **Цифры не совпадают с «Проверь себя»** — возможно, база изменилась, пока ты тестировал. Загрузи `shop.sql` заново (шаг 1).
- Ничего не помогает — пиши в наш Telegram-чат, приложи скриншот.
